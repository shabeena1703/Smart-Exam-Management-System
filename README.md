DESCRIPTION:
The Online Examination System is a console-based application developed using C++. 
The project provides separate modules for administrators and students.
Administrators can register, log in, add examination questions, and view student results. Students can register, log in, take the 
examination, and view their results after completion.
The system uses file handling to store student records, admin details, questions, and examination results. It also ensures that a student 
cannot take the same examination more than once without administrator permission.

FEATURES:
Admin Registration and Login
Student Registration and Login
Add Examination Questions
Take Online Examination
Automatic Result Calculation
View Student Results
View All Results (Admin)
File-Based Data Storage
One-Time Exam Attempt Restriction

TECHNOLOGIES USED:
C++
Object-Oriented Programming (OOP)
File Handling

CHALLENGES:
As a beginner in C++, I faced several challenges while developing this project:
Implementing file handling for storing and retrieving data.
Developing separate login systems for admins and students.
Reading and displaying exam questions correctly from files.
Calculating results automatically and preventing multiple exam attempts.
Handling invalid inputs and debugging program errors.

This project helped me strengthen my understanding of C++, Object-Oriented Programming (OOP), and file handling concepts.
